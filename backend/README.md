# Backend

NestJS authoritative game server with SQLite persistence and `ws` realtime
transport. See `../README.md` for the assignment, design, and root commands.

From this directory: `npm run start:dev`, `npm test`, `npm run test:e2e`,
`npm run build`, or `npm run start:prod` (after building). Node 24 is required.
The production server also serves the built client in `../frontend/dist`.
